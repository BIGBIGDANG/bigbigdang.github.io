ToGo: Planning Dexterous Tool Use via Tool-Centric Functional Goal-Trajectory Generation

ToGo represents dexterous tool use through functional tool geometry and tool–environment interaction constraints. A VLM-grounded geometric planner identifies functional tool parts and scene targets, then compiles them into staged SE(3) tool-pose goals for execution.

Mingzhi Chen, Liqi Yan, Fangli Guan, Bin Lin, Dingran Dong, Pan Li

Medical Vision · Efficient Deep LearningESWA 2026 · Accepted

PinNet: Edge-Optimized Skin Lesion Segmentation

PinNet is an ultra-lightweight segmentation architecture designed for ambiguous lesion boundaries and edge deployment. It combines morpho-spectral feature extraction with dual-perspective attention using approximately 0.05M parameters and 0.068 GFLOPs.

Mingzhi Chen, Zhaoyang Xu, Gaopeng Huang, et al.

Computational Imaging · Representation LearningResearch Project

Non-Line-of-Sight Reconstruction via Target-Domain Latent Alignment

This project decomposes NLOS reconstruction into two simpler stages: learning a compact latent prior from clean target images, then aligning degraded NLOS measurements to that target space. A fixed decoder reconstructs images from the aligned representation.
