Tool semantics→Functional geometry→SE(3) goals

Embodied AI · Robot Manipulation

ToGo: Planning Dexterous Tool Use via Tool-Centric Functional Goal-Trajectory Generation

We formulate dexterous tool use as tool-centric functional goal-trajectory generation, representing manipulation through functional tool geometry and tool-environment interaction constraints.

A VLM-grounded geometric planner identifies functional tool parts and interaction targets from language, tool geometry, and RGB-D observations, then compiles them into staged SE(3) tool-pose goals.

NLOS→Latent prior→Target

Computational Imaging · Representation Learning

Non-Line-of-Sight Reconstruction via Target-Domain Latent Alignment

We recast NLOS reconstruction as target-domain latent alignment, learning a compact representation from clean target images as a structural prior for reconstruction.

The method decouples target representation learning from NLOS inversion by learning the target latent space and decoder first, then aligning degraded measurements to that space.

Boundary modeling+Lightweight design

Medical Vision · Efficient Deep Learning

PinNet: Edge-Optimized Skin Lesion Segmentation

PinNet is an ultra-lightweight segmentation architecture for ambiguous lesion boundaries and scale variation, combining morpho-spectral feature extraction with dual-perspective attention.

The model uses approximately 0.05M parameters and 0.068 GFLOPs.
