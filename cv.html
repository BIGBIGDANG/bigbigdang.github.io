Tool-Centric Planning for Dexterous Tool Use

Mar. 2026 – Jul. 2026

  • Formulated dexterous tool use as tool-centric functional goal-trajectory generation, representing manipulation tasks through functional tool geometry and tool-environment interaction constraints.
  • Developed a VLM-grounded geometric planning pipeline that grounds functional tool parts and interaction targets from language, tool geometry, and RGB-D observations, then compiles them into staged SE(3) tool-pose goals for execution by a pretrained goal-tracking policy.

Non-Line-of-Sight Reconstruction via Target-Domain Latent Alignment
